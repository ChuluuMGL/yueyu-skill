# Brand Assets

This folder keeps the canonical brand assets used by the public skill package.

## Files

- `yueyu-logo-wordmark.png` — official YUEYU wordmark copied from the live website asset `YUEYUTECH Website/public/logo.png`.
- `../../social-preview.png` — GitHub README / social preview image that uses the YUEYU wordmark.

## Rules

- Use the `YUEYU` wordmark for this skill's README, social preview, and package pages.
- Do not use the older `月瑀营销 / MONSTO MKT` mark for this skill package. That mark appeared in legacy company-presentation files and is not the correct public logo treatment for `yueyu-skill`.
- If the website logo changes, update `yueyu-logo-wordmark.png`, regenerate `social-preview.png`, and verify the README image before release.
